= Contributing
:description: How to contribute to the AsciiDoc extension.

Contributions are welcome.
Create an issue to discuss your change first, then clone the repository, commit your changes, and open a pull request.
In the pull request description, clearly highlight what you changed.

The full set of rules (commit messages, changelog, tests, localization) is described in the {url-repo}/blob/main/CONTRIBUTING.adoc[contributing guide].

[NOTE]
====
Do not update the extension version -- maintainers do this when a new version is released.
====

== Documentation changes

You are free to fix typos and errors, and to add or improve descriptions.
As with any other change, please create an issue first so it can be discussed.
